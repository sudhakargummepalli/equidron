Let Razorpay orders skip the token check that the simulated provider needs

placeOrder validated a payment token before doing anything, which is right for card, UPI, COD and
bank - each carries a token the provider can check. A gateway payment has no token at that moment:
its proof arrives later as a signed (order, payment) pair. The check rejected the order with
"Unknown payment option" before the modal could open, which is the error seen on checkout.

Verified against the real Razorpay test API: POST /shop/orders with payment_method razorpay creates
order #34, and POST /shop/payments/razorpay/order returns order_TtfqG7jijSgqEl for 22900 paise.
